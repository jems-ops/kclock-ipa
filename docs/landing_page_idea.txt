SSO Onboarding Wizard

Step-Based Workflow

Step 1 — Select Application

Select integration target:
[ Jenkins ] [ SonarQube ] [ Wazuh ] [ Jira ]

Step 2 — Identity Settings

Fields:

* App URL
* SAML/OIDC
* Group Mapping
* NameID
* Redirect URI

Step 3 — Generate Config

System automatically:

* Creates Keycloak client
* Generates metadata
* Configures mappers
* Applies automation

Step 4 — Validation

✔ Metadata validated
✔ SAML login tested
✔ Group mapping verified
✔ Role assignment validated
