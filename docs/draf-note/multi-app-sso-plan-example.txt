Below is a more production-ready rewrite of the role design for Keycloak + FreeIPA with:
idempotent checks


realm session settings


create-or-update logic instead of blind create


per-app attribute mapping


optional per-app group mapping


cleaner task flow


vault-ready variables


This version is built for your goal:
one FreeIPA username/password
multiple SAML apps
one Keycloak realm for SSO

Recommended structure
roles/
  keycloak_saml_federation/
    defaults/
      main.yml
    tasks/
      main.yml
      prereqs.yml
      auth.yml
      realm.yml
      ldap_provider.yml
      ldap_mappers.yml
      saml_clients.yml
      saml_mappers.yml
      sync.yml
      validate.yml
    templates/
      ldap-provider.json.j2
      ldap-user-attr-mapper.json.j2
      ldap-group-mapper.json.j2
      saml-client.json.j2
      saml-nameid-mapper.json.j2
      saml-user-property-mapper.json.j2
      saml-group-membership-mapper.json.j2
    handlers/
      main.yml

4) Prereqs
tasks/prereqs.yml
- name: Ensure temp working directory exists
  ansible.builtin.file:
    path: "{{ keycloak_tmp_dir }}"
    state: directory
    mode: "0755"

- name: Check kcadm exists
  ansible.builtin.stat:
    path: "{{ keycloak_kcadm }}"
  register: _kcadm_stat

- name: Fail if kcadm is missing
  ansible.builtin.fail:
    msg: "kcadm.sh not found at {{ keycloak_kcadm }}"
  when: not _kcadm_stat.stat.exists

6) Realm with update logic
tasks/realm.yml
- name: Check if realm exists
  ansible.builtin.command: >
    {{ keycloak_kcadm }} get realms/{{ keycloak_realm }}
  register: _realm_get

7) LDAP provider create-or-update
tasks/ldap_provider.yml
- name: Get realm components
  ansible.builtin.command: >
    {{ keycloak_kcadm }} get components -r {{ keycloak_realm }}
  register: _components_raw
  changed_when: false

- name: Extract LDAP provider id
  ansible.builtin.shell: |
    cat <<'EOF' | python3
    import json
    data = json.loads('''{{ _components_raw.stdout | replace("'", "\\'") }}''')
    matches = [x for x in data if x.get("name") == "{{ keycloak_ldap_provider_name }}" and x.get("providerId") == "ldap"]
    print(matches[0]["id"] if matches else "")
    EOF
  register: _ldap_provider_id
  changed_when: false

- name: Set LDAP provider fact
  ansible.builtin.set_fact:
    keycloak_ldap_provider_id: "{{ _ldap_provider_id.stdout | trim }}"

- name: Render LDAP provider payload
  ansible.builtin.template:
    src: ldap-provider.json.j2
    dest: "{{ keycloak_tmp_dir }}/ldap-provider.json"
    mode: "0644"

- name: Create LDAP provider if missing
  ansible.builtin.command: >
    {{ keycloak_kcadm }} create components -r {{ keycloak_realm }}
    -f {{ keycloak_tmp_dir }}/ldap-provider.json
  when: keycloak_ldap_provider_id | length == 0

- name: Refresh LDAP provider id after create
  ansible.builtin.command: >
    {{ keycloak_kcadm }} get components -r {{ keycloak_realm }}
  register: _components_raw_after
  changed_when: false
  when: keycloak_ldap_provider_id | length == 0

- name: Extract LDAP provider id after create
  ansible.builtin.shell: |
    cat <<'EOF' | python3
    import json
    data = json.loads('''{{ _components_raw_after.stdout | replace("'", "\\'") }}''')
    matches = [x for x in data if x.get("name") == "{{ keycloak_ldap_provider_name }}" and x.get("providerId") == "ldap"]
    print(matches[0]["id"] if matches else "")
    EOF
  register: _ldap_provider_id_after
  changed_when: false
  when: keycloak_ldap_provider_id | length == 0

- name: Finalize LDAP provider id
  ansible.builtin.set_fact:
    keycloak_ldap_provider_id: >-
      {{
        (keycloak_ldap_provider_id | length > 0)
        | ternary(keycloak_ldap_provider_id, _ldap_provider_id_after.stdout | trim)
      }}

- name: Update LDAP provider config
  ansible.builtin.command: >
    {{ keycloak_kcadm }} update components/{{ keycloak_ldap_provider_id }} -r {{ keycloak_realm }}
    -f {{ keycloak_tmp_dir }}/ldap-provider.json
  changed_when: true

13) What this improves
Compared with the earlier version, this one fixes the main production gaps:
1. Idempotency
It does not blindly create realms, LDAP providers, mappers, or clients every run.
2. Update support
If ACS URL, redirect URI, NameID, or mapper values change, the role updates them.
3. One realm, many apps
That gives you real SSO with one login session across all apps.
4. Per-app flexibility
Different apps can have:
different ACS URLs


different client IDs


different attribute sets


different group mapping behavior


5. Cleaner maintenance
Most of the app-specific differences live in variables, not in task code.

16) Best practice for your environment
For your project, I would keep this model:
FreeIPA = authoritative users/groups/passwords


Keycloak = SAML IdP and SSO broker


One realm = shared login session


Many SAML clients = SonarQube, Jenkins, Artifactory, others


That is the cleanest way to let users sign in once with the same FreeIPA-backed credentials and then access multiple apps through Keycloak.
